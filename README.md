## Featured Projects

### 🛡️ [VendorGuard AI](https://github.com/agrima150103/vendorguard-ai) — Human-Governed Multi-Agent Vendor Risk Platform
Built as capstone for the **Kaggle x Google 5-Day AI Agents Intensive**. Four cooperating agents (evidence, risk/security, policy, decision) orchestrated on **Google's Agent Development Kit**, with policy checks served over **MCP** and a human-in-the-loop approval gate — because an agent pipeline that can't be audited shouldn't be trusted with real decisions.
`Python` `FastAPI` `React` `Google ADK` `MCP` `Firebase` `Render`
[Live Demo](https://vendorguard-web.web.app/)

### 🏥 [GenAI Atlas](https://github.com/agrima150103/genai-clinical-intelligence) — Multi-Agent Clinical Intelligence Platform
Six specialized agents for early detection of silent treatment failures in hospital care — the kind of slow decline that's easy for a busy care team to miss. Combines **Groq-hosted Llama 3** reasoning with rule-based medical guardrails so every output stays explainable. **Semi-Finalist, The Economic Times AI Hackathon 2026.**
`Python` `Streamlit` `LLM Agents` `Rule-Based Guardrails`

### 🚦 [MARL Traffic Signal Management](https://github.com/agrima150103/MARL-Driven-Real-Time-Traffic-Management-System)
Multi-agent reinforcement learning for adaptive traffic signals — each intersection learns its own timing from live queue length and emergency-vehicle presence. Simulated in **SUMO**, secured with **TLS 1.3 / SHA-256** inter-agent messaging. Filed as an **Indian Patent Application**.
`Python` `Reinforcement Learning` `SUMO` `YOLO` `TLS 1.3`

### 🔍 [CyberShield](https://github.com/agrima150103/cybershield-project) — Real-Time Cyber Threat Intelligence Platform
A unified console pulling reconnaissance, phishing detection and network analysis into one place, instead of a dozen disconnected tools. ML-based phishing classifier (Random Forest + Gradient Boosting) alongside Nmap/GoPhish/Shodan integrations and real-time WebSocket alerts.
`Node.js` `Express` `React` `scikit-learn` `WebSockets`

### 🪪 [TrustID](https://github.com/agrima150103/TrustID-UBID-Intelligence) — Unique Business ID Resolution & Intelligence Platform
Solo build, **Top 50 nationwide finalist** at AI for Bharat Hackathon 2026. Matches and resolves business identity records with confidence scoring and a full audit ledger, so every automated match stays reviewable by a human.
`React` `Node.js` `SQLite`
[Live Demo](https://trust-id-ubid-intelligence.vercel.app/)
